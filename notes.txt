2. Complete the Settings Page (/settings)
The settings page is currently a placeholder. We can quickly make it functional by adding:

4. Date Filtering for History & Stats
Current State: The /history and /stats pages fetch all transactions ever made. As the app grows, this will clutter the UI and distort monthly budgeting.

5. Fix the Auto-Refresh Bug on Deletion
Current State: When deleting an item in TransCardTools, you call router.refresh(). In the Next.js App Router, this doesn't reliably trigger a re-fetch of client-side state inside a useEffect.
Improvement: We should lift the state up, or dispatch a custom window event / pass a callback function so that the parent component (History/Dashboard) knows to immediately remove the item from the React state without a full page reload.
